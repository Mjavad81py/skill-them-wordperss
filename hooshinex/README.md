# Hooshinex — قالب فروشگاهی وردپرس

قالب وردپرس فروشگاه محصولات دیجیتال «هوشینکس»، ساخته‌شده بر پایه Elementor Theme Builder
و WooCommerce. راست‌به‌چپ، سئو-محور و سبک.

> **معماری:** ویجت‌ها داخل قالب نیستند. آن‌ها در افزونهٔ همراه
> `hooshinex-widgets` قرار دارند تا با عوض کردن قالب، محتوای صفحات از بین نرود.

---

## پیش‌نیازها

| مورد | حداقل نسخه |
| --- | --- |
| WordPress | 6.0 |
| PHP | 7.4 |
| Elementor | 3.5 |
| Elementor Pro | برای Theme Builder (اختیاری ولی توصیه‌شده) |
| WooCommerce | 8.0 (برای بخش فروشگاه) |

بدون Elementor Pro هم سایت کار می‌کند؛ قالب برای هدر، فوتر، آرشیو و تک‌نوشته
مارک‌آپ فالبک دارد.

---

## نصب

1. پوشهٔ `hooshinex` را در `wp-content/themes/` بگذارید و از **نمایش ← پوسته‌ها** فعالش کنید.
2. پوشهٔ `hooshinex-widgets` را در `wp-content/plugins/` بگذارید و فعال کنید.
3. WooCommerce را نصب و راه‌اندازی کنید.
4. به **نمایش ← راه‌اندازی هوشینکس** بروید و دکمهٔ ساخت صفحات را بزنید.

### گام ۴ چه کار می‌کند؟

یک‌بار و بدون بازنویسی محتوای موجود:

- صفحات ضروری را می‌سازد: صفحه اصلی، وبلاگ، درباره ما، تماس با ما، سوالات متداول،
  قوانین و مقررات، حریم خصوصی، راهنمای خرید، همکاری در فروش.
- صفحهٔ اصلی و صفحهٔ نوشته‌ها را در تنظیمات خواندن ست می‌کند.
- منوی «اصلی» را با لینک‌های فروشگاه، وبلاگ، درباره ما، سوالات متداول و تماس می‌سازد.
- شناسهٔ صفحات را در آپشن `hooshinex_pages` نگه می‌دارد تا قالب بتواند به آن‌ها لینک بدهد.

اگر صفحه‌ای با همان نامک از قبل وجود داشته باشد، همان استفاده می‌شود.

| فروشگاه | تعداد محصول در ردیف، تعداد محصول در صفحه |

## چیدمان صفحه اصلی

`front-page.php` به این ترتیب عمل می‌کند:

1. اگر قالبی در Theme Builder به موقعیت `single` وصل باشد، همان اجرا می‌شود.
2. وگرنه اگر صفحهٔ اصلی محتوا داشته باشد (المنتور یا ویرایشگر بلوک)، همان نمایش داده می‌شود.
3. وگرنه بخش‌های پیش‌فرض قالب رندر می‌شوند:
   هیرو ← دسته‌بندی‌ها ← محصولات ویژه ← بنرهای دوقلو ← جدیدترین محصولات ←
   بنر تخفیف ← محصول شگفت‌انگیز ← وبلاگ ← پرسش‌ها ← فروشنده شوید.

هر بخش داده‌اش را از خود وردپرس/ووکامرس می‌گیرد؛ هیچ دادهٔ ساختگی‌ای در قالب نیست.
بخش‌هایی که داده ندارند (مثلاً وقتی محصول تخفیف‌دار وجود ندارد) خودشان را نمایش نمی‌دهند.

## قالب‌های برگه

| قالب | کاربرد |
| --- | --- |
| المنتور تمام عرض | محتوا تمام‌عرض، بدون عنوان و نوار کناری |
| المنتور بوم خالی | فقط محتوا، بدون هدر و فوتر |
| صفحه تماس با ما | کارت‌های اطلاعات تماس + فرم پیام |
| صفحه سوالات متداول | آکاردئون؛ سوال‌ها از تیترها و پاراگراف‌های همان برگه خوانده می‌شوند |

در برگهٔ سوالات متداول کافی است هر سوال را با `<h2>`/`<h3>` و پاسخش را زیر آن
بنویسید؛ قالب خودش آن را به آکاردئون تبدیل می‌کند. اگر برگه خالی باشد، یک مجموعهٔ
پیش‌فرض مناسب فروشگاه نمایش داده می‌شود.

## جستجوی زنده

- مسیر REST: `GET /wp-json/hooshinex/v1/search?q=…` (عمومی، حداقل ۲ نویسه)
- تا ۸ نتیجه شامل محصول، نوشته و دسته‌بندی محصول
- میان‌بر `Ctrl` + `K` روی اولین فیلد جستجوی قابل مشاهده فوکوس می‌کند

---

## فونت

فایل‌های فونت **استعداد** همراه قالب ارسال نمی‌شوند.
راهنمای افزودن آن‌ها: [`assets/fonts/README.md`](assets/fonts/README.md).
بدون آن‌ها هم قالب با `Vazirmatn` / `IRANSans` / Tahoma به‌درستی کار می‌کند.

---

## سئو

قالب اگر افزونهٔ سئو فعال ببیند (Yoast، Rank Math، AIOSEO، SEOPress، Slim SEO، TSF)
**هیچ** متا تگ و **هیچ** JSON-LD چاپ نمی‌کند. در نبود افزونه، خودش
description، canonical، Open Graph، Twitter Card و یک گراف JSON-LD یکپارچه تولید می‌کند.

اسکیمای `Product` هرگز توسط قالب تولید نمی‌شود؛ آن وظیفهٔ ووکامرس است.

## توسعه

```
hooshinex/
├── inc/                    # setup, enqueue, elementor, customizer, search, pages, seo, schema, performance, woocommerce
├── template-parts/
│   ├── header-default.php  # فالبک هدر
│   ├── footer-default.php  # فالبک فوتر
│   ├── archive-loop.php    # حلقهٔ مشترک آرشیو/جستجو
│   └── home/               # بخش‌های صفحه اصلی
├── templates/              # قالب‌های برگه
├── assets/js/app.js        # درایو، مگامنو، جستجوی زنده، اسلایدر، شمارش معکوس، توست
└── languages/hooshinex.pot
```

### قلاب‌های مفید

| قلاب | نوع | کاربرد |
| --- | --- | --- |
| `hooshinex_persian_digits` | filter | خاموش/روشن کردن تبدیل ارقام فارسی |
| `hooshinex_default_faq` | filter | تغییر سوالات پیش‌فرض |
| `hooshinex_products_per_row` | filter | تعداد ستون‌های آرشیو محصول |
| `hooshinex_products_per_page` | filter | تعداد محصول در هر صفحه |
| `hooshinex_needs_woocommerce_assets` | filter | نگه‌داشتن اسکریپت‌های ووکامرس در صفحه‌ای خاص |

### ساخت فایل ترجمه

```bash
wp i18n make-pot . languages/hooshinex.pot --domain=hooshinex
```
